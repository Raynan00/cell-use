Proposed next demo flow: import a screenshot of song recommendations, review the extracted track list, then build a Spotify playlist through its interface. This flow needs screenshot import and a Spotify destination added to the app.

> The best song recommendations are buried in the comments. I wanted them in a playlist.

## The hook

> What if your iPhone could do the tapping?

Show the actual phone doing the work before explaining the SDK. Target a 45 to 60 second edit from one continuous screen recording. Let the successful run determine the edit length.

## Before recording

- Install and pair Playlist Move, connect, and finish the Apple Intelligence and speech model downloads.
- Complete a one-song transfer before the five-song take. Use a small playlist with clear track titles and artists.
- Choose a fresh destination name for this take. Keep a copy of the source playlist link ready to paste after voice input.
- Use Focus to silence unrelated notifications. Keep the phone in portrait and the screen awake. Leave music playback off.
- Try a short screen recording with its microphone on while speaking to the app. Play it back to check audio. If microphone sharing interferes, record with the screen recorder's microphone off and add narration afterward.
